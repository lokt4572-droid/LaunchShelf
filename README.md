# LaunchShelf

LaunchShelf is a Django marketplace for buying and selling digital projects.

## Built with

* Python
* Django
* PostgreSQL
* HTML / CSS / JavaScript
* Bootstrap

## Features

* User registration and login
* Email verification
* User profiles
* Project listings
* Search and filters
* Seller contact
* PostgreSQL support

## Run locally

```bash
git clone https://github.com/lokt4572-droid/LaunchShelf.git
cd LaunchShelf

python -m venv .venv
.venv\Scripts\Activate.ps1

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Create a `.env` file with your Django, database, and email settings before running the project.
